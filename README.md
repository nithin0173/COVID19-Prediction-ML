# Prediction of COVID-19 using Machine Learning

## 🔬 Project Overview
This research project developed a machine learning model to accurately predict COVID-19 infection based on patient clinical data. The system serves as a decision-support tool for early clinical intervention.

## 🚀 Key Results
* **High Classification Performance:** Successfully identified high-risk cases using XGBoost.
* **Early Detection:** Optimized for Recall to minimize false negatives in medical screening.
* **Clinical Interface:** Includes a functional dashboard for real-time risk assessment.

## 🛠️ Tech Stack
* **Language:** Python
* **Model:** XGBoost Classifier
* **Library:** Scikit-Learn, Pandas, Joblib
* **Deployment:** Streamlit
